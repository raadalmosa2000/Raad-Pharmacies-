# 🏥 صيدلياتنا (Saydaliyatna)

تطبيق أندرويد متكامل وذكي يهدف إلى تسهيل وصول المرضى إلى الأدوية والصيدليات القريبة والمناوبة، مع توفير أدوات حديثة لإدارة الصحة ومساعدة الصيادلة في إدارة صيدلياتهم.

## ✨ الميزات الرئيسية (Features)

### 👤 للمرضى والمستخدمين:
*   **البحث المتقدم:** العثور على الأدوية والصيدليات المناوبة والمفتوحة القريبة منك.
*   **الخريطة التفاعلية:** استعراض الصيدليات على الخريطة ومعرفة المسافات بدقة (مبني على OSMDroid).
*   **قارئ الوصفات الذكي (Gemini AI):** قراءة وتحليل الوصفات الطبية فور تصويرها باستخدام الذكاء الاصطناعي.
*   **التذكير بمواعيد الدواء:** نظام متكامل لإدارة جرعات الأدوية اليومية وحفظ سجل للمواعيد.
*   **المفضلة وتفاصيل الصيدلية:** الاتصال المباشر، الحصول على الاتجاهات، مشاركة الموقع، ومعرفة الخدمات الطبية الإضافية للصيدلية.

### 👨‍⚕️ للصيادلة (لوحة التحكم):
*   **التحكم السريع بالحالة:** تبديل حالة الصيدلية بضغطة زر (مفتوحة، أو في حالة مناوبة ليلية).
*   **إدارة المتجر:** واجهات لإدارة الأدوية، استقبال طلبات الوصفات، وتحديث أوقات الدوام الرسمي.
*   **ملخص الأداء:** متابعة عمليات البحث عن أدويتك وإحصائيات تفاعل العملاء.

## 🛠️ التقنيات المستخدمة (Tech Stack)
*   **اللغة:** Kotlin
*   **واجهة المستخدم:** Jetpack Compose (Material Design 3)
*   **الخرائط:** OSMDroid
*   **الذكاء الاصطناعي:** Google Gemini AI
*   **التنقل:** Navigation Compose
